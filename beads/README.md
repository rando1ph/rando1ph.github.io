# 拼豆图纸生成器

完整移植 [Bead Grid Studio / 豆格工坊](https://github.com/zwhy149/bead-grid-studio)，
固定上游提交 `f3d8c261f7005a2f619d3db6061ce3649a59720e`（应用版本 1.3.0）。
访问路径为 `/beads/`，适用于当前仓库直接发布的 GitHub Pages 静态站点。

## 结构与维护

- `upstream/`：完整、未修改的上游源码、测试、文档、原始许可证与声明。
- `site/`：本网站的导航和深色主题。
- `scripts/build.mjs`：复制上游到临时目录，应用中文化、站点路径、缓存与主题适配，再构建完整应用。
- `index.html`、`assets/`、`offline.html` 等：需要提交的静态发布产物，请勿手工修改。
- `tests/`：针对真实 `/beads/` 子路径的桌面及手机端浏览器回归测试。
- `.work/`、`node_modules/` 与测试报告：忽略提交的临时文件。

保留上游图片转换算法、221 色色板、智能推荐、裁剪、画笔/橡皮/取色、撤销重做、
旋转镜像、坐标与色号、底板拼接、用料统计、逐色制作进度、草稿恢复、
PNG 图纸、JSON 工程、CSV 清单、宣传图、浏览器分页打印与完整单文件离线版。
本地适配仅改变集成、界面与发布设置，不改变豆子颜色或图纸渲染算法。

适配中还修正了上游界面的三处问题：补齐工具状态中文词条与撤销提示参数，
避免语言切换监听器绑定到根元素后抢走画布键盘焦点，以及为手机抽屉的
快捷滚动预留固定标题高度，防止材料清单导出按钮被遮挡。

## 构建与验证

要求 Node.js >= 22.12 和 Python 3（测试静态服务器）。从仓库根目录运行：

```sh
npm --prefix beads ci
cd beads
npx playwright install chromium
npm run check
npm run build
npm test
npm run test:upstream
```

`npm test` 在 4180 端口启动整个仓库的静态服务器，覆盖桌面与手机；
`npm run test:upstream` 独立构建上游并在 4173 端口验证上游原始测试。
测试包含 82 项浏览器内部自检、图片转换、编辑与撤销重做、工程往返、
PNG/CSV 导出、材料总数、制作进度恢复、离线运行、站点导航及响应式布局。

构建后直接提交发布产物，无需服务器、在线构建服务或运行时 CDN。
本地预览可在仓库根目录运行 `python3 -m http.server 8000` 后访问
`http://localhost:8000/beads/`。

## 本地处理与离线

图片通过浏览器文件接口读取，转换、编辑、统计、导出均在本地运行。
无上传接口、遥测或第三方运行时资源；页面 CSP 的 `connect-src data: blob:`
阻止页面发起 HTTP 数据提交。内置示例图片嵌入应用，亦可离线转换。
草稿使用 `randolf:beads:draft:v2`，不包含原图。

Service Worker 仅控制 `/beads/`，仅清理 `randolf-beads-` 前缀缓存；
缓存版本由构建内容确定，保留其他网站工具的缓存。
“下载离线版”下载本站中文适配后的单文件 HTML，包含完整应用和版权声明。
