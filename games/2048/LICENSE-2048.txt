This notice covers the gameplay logic in games/2048/2048.js, which is
adapted from the canonical 2048 implementation by Gabriele Cirulli
(https://github.com/gabrielecirulli/2048, MIT licensed):

  - direction vectors and traversal-order construction
    (original: js/game_manager.js getVector / buildTraversals)
  - farthest-position search used for sliding
    (original: js/game_manager.js findFarthestPosition)
  - the one-merge-per-tile-per-move rule and merge scoring
    (original: js/game_manager.js move)
  - game-over detection via available-moves check
    (original: js/game_manager.js movesAvailable / tileMatchesAvailable)
  - spawn probability (90% "2", 10% "4")
    (original: js/game_manager.js addRandomTile)

All other code — DOM rendering and animation, touch/keyboard input,
undo, deterministic-spawn persistence, overlays, audio hooks — is
original randolf.dev code. The original visual design was not used.
