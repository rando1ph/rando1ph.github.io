THIRD-PARTY NOTICES — Cow Cat Can Fly (randolf.dev/games/cow-cat-can-fly/)
===========================================================================

This game is an original implementation. No art, audio, branding or
visual assets were copied from any third-party project.

Before implementation, the following MIT-licensed open-source Flappy-style
browser games were inspected. Algorithmic concepts were studied and
re-implemented in original code; where patterns were closely adapted
(delta-time clamping, bounded vertical gap shifts, a per-obstacle
"scored" flag, a post-game-over restart guard), this file preserves the
notices of those projects as a courtesy under the MIT license.

1) CrappyBird
   https://github.com/varunpant/CrappyBird
   Copyright (c) 2014 Varun Pant — MIT License
   Studied: entity/state architecture, velocity-based flight model,
   AABB collision.

2) flappy-bird
   https://github.com/pyforgedev/flappy-bird
   Copyright (c) 2026 Masyura Fanni Ramadhan (pyforgedev) — MIT License
   Studied/adapted: delta-time loop with maximum-step clamp, bounded
   vertical delta between consecutive gap centers, score-exactly-once
   flag, delayed restart acceptance after game over.

3) flappybird
   https://github.com/shuding/flappybird
   Copyright (c) 2020 Shu Ding — MIT License
   Studied: touch input handling for mobile browsers.
