How the bay works

Every energy core has to end up seated in a dock. Cores only move when the robot pushes them — never pull, never carry — and a core pushed into a corner is stuck there for good. The robot can always be sent around the long way, so the order you push in matters more than the distance.

Desktop — arrow keys or WASD to move, Z to undo, R to restart, L for levels, H for a hint.

Touch — tap open deck to walk there, tap a core to see where it can be pushed, or swipe a single step.

Power is live, not a score: pull a core back out of its dock and the ship's circuits go dark again, exactly as far as you undid.
